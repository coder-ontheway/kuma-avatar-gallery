# KUMA STUDIO｜多系列原創收藏管理平台 操作說明

網站以「**系列**」為最上層管理單位。每個系列有自己的封面、主視覺、作品、編號、稱號、身份證、宣言、收藏卡，以及**自己的粉絲下載密碼**。
之後推出新的熊兔主題（熊大寵妻、甜蜜日常、旅行約會…），只要在後臺新增系列、上傳照片、設定資料與密碼，**不需要修改程式或重新部署**。

```
KUMA STUDIO 收藏館
├── 熊兔生命共同體（既有，網址 #/c/one-heart-one-life，舊網址 #/life 仍可用）
│   ├── No.001 熊兔共生體 …
├── 熊大寵妻系列（#/c/pamper-wife）
│   ├── No.001 睡前貼心照顧（劇情照＋配套大頭貼）…
├── 熊兔甜蜜日常 …
└── 未來新增系列（數量不限，每個系列的作品數也不限）
```

原本的「大頭貼收藏館」（首頁下方 Facebook／Instagram／LINE 大頭貼）完整保留，使用「網站設定」裡原本的下載密碼，和各系列的密碼互相不通用。

## 一、第一次升級（已部署過的網站）

1. Supabase → **SQL Editor** → 貼上 `supabase/migrations/20261103000000_kuma_studio_collections.sql` 全部內容 → **Run**，看到 `Success` 即可（可重複執行）。
   - 不刪除、不重建任何資料：既有的「熊兔生命共同體」自動變成狀態「公開」，原本設定的生命共同體密碼**繼續有效**（粉絲手上的密碼不用換）。
2. 合併到 main 後，GitHub Actions 會自動重新部署網站與下載功能（Edge Function）。若 Edge Function 沒有自動部署，到 **Actions → 部署下載功能（Edge Function）→ Run workflow**。
3. 登入 `網站網址/#/admin`，會直接進入「**系列管理中心**」。

> 順序很重要：請先執行 SQL，再讓新版網站上線。若網站先上線，後臺會提示「請先執行 …20261103000000_kuma_studio_collections.sql」。

---

### 升級：作品額外大頭貼

在 SQL Editor 執行 `supabase/migrations/20261104000000_work_extra_avatars.sql`（只新增一張資料表，不動既有資料，可重複執行）。沒執行前，後臺按「＋ 其他款大頭貼」會提示先執行這個檔案，網站其他功能不受影響。

## 二、系列管理中心（後臺首頁）

每個系列一列，清楚顯示：

| 顯示 | 說明 |
| --- | --- |
| 系列名稱、英文名稱、封面 | 點封面或「管理系列」進入該系列 |
| 狀態 | 草稿／公開／已下架 |
| 密碼 | 密碼已設定／密碼已停用／未設定密碼 |
| 下載 | 可下載／下載未開放（未公開或密碼未啟用）／下載已關閉 |
| 作品數 | 作品幾款、已上傳照片、已公開幾款 |
| 近 48 小時密碼驗證 | 粉絲輸入該系列密碼成功與失敗的次數（不記錄粉絲身分與密碼內容） |
| ↑ ↓ | 調整系列在首頁的排序 |

上方導覽：系列管理｜大頭貼作品（原本收藏館）｜分類管理｜網站設定｜管理紀錄。

## 三、新增一個系列（例：熊大寵妻系列）

1. 系列管理中心 →「**＋ 新增系列**」。
2. 填寫：
   - **系列名稱**：熊大寵妻系列
   - **英文名稱**：PAMPER MY BUNNY
   - **網址代稱**：留空會依英文名稱自動產生（例 `pamper-my-bunny`），也可以自己填 `pamper-wife`。粉絲網址就是 `網站網址/#/c/pamper-wife`
   - **主題標語**、**身份證標題**（例：熊大寵妻身份證）、**宣言名稱**（例：寵妻宣言）
   - **收藏卡主題**：森林共生／甜蜜寵愛／暖陽日常／晴空旅行／星夜守護／經典奶茶（版面與 KUMA STUDIO 標示一致，只換配色與裝飾）
3. 按「建立系列」，系列先存成**草稿**（粉絲看不到），自動進入該系列的管理頁。

### 系列管理頁的內容（由上而下）

1. **專屬下載密碼**（見第四節）
2. **系列設定**：名稱、英文名稱、狀態、網址代稱、主題標語、系列介紹、**這個系列的預設宣言**（一行一句，最多 30 句）、身份證標題、宣言名稱、收藏卡主題、**啟用身份證**、**啟用收藏卡**、**開放粉絲下載這個系列**、系列排序
3. **系列封面與主視覺**：封面用在首頁系列卡片；主視覺是系列頁最上方的大圖。沒設定時都使用第一款作品
4. **上傳照片**（單張或批次）
5. **作品清單**：每款可編輯資料、替換照片、上傳／替換／移除大頭貼版、保護區域、預覽收藏卡、公開／下架、刪除、↑↓ 排序；「＋ 新增一款」
6. **最近的管理紀錄**
7. **刪除系列**

### 上傳作品

- 在「上傳照片（可一次選多張）」選檔案。**每張照片都是一款獨立作品**，不會合成在一起，也不會用 AI 補圖。
- 檔名有編號時自動對應：`No.003.jpg`、`003_星空.jpg`、`bear_loves_rabbit_03_umbrella.png` → No.003。其他檔案依檔名順序填入。
- **劇情照＋配套大頭貼**：檔名含 `avatar` 或「大頭貼」的檔案會存成同編號作品的「**大頭貼版**」。
  例如一次選這 10 個檔案，會建立 **5 款作品**，每款各有劇情照與大頭貼版：
  `bear_loves_rabbit_01_bedtime.png`＋`bear_loves_rabbit_avatar_01_bedtime.png` → No.001 …
  - 劇情照：用於身份證、收藏卡、作品卡片
  - 大頭貼版：粉絲製作 Facebook／Instagram／LINE 大頭貼時使用
  - 兩張都以原始檔案原封不動存在私有空間，下載都需要該系列的密碼
- **同一款作品有多張大頭貼**：在作品清單按「＋ 其他款大頭貼」（可一次選多張），會加為第 2、3…款，原本的大頭貼版保留。粉絲製作大頭貼時可以在「選擇大頭貼款式」切換；縮圖右上角「×」可移除單張。額外大頭貼同樣原檔原封不動存在私有空間，下載需要該系列的密碼。
- 上傳前可以在清單中修改每個檔案要對應的編號。上傳後作品是**草稿**。
- 不同系列的作品編號可以重複（熊兔生命共同體 No.001 與熊大寵妻 No.001 互不衝突）；同一系列內不能重複。

### 編輯作品資料

「編輯資料」可修改：作品編號、排序、**專屬稱號**、作品名稱、主題概念、作品介紹、**主題宣言**、是否開放下載。所有文字都由管理員填寫，沒有寫死在程式。

### 公開

1. 作品清單 →「公開所有已上傳的草稿」（或逐款按「公開」）。
2. 系列設定 → 狀態改成「**公開**」→ 儲存。首頁馬上出現這個系列。
3. 想暫時不讓粉絲看到：狀態改成「**已下架**」（粉絲看不到、也不能下載，資料都保留）。

## 四、每個系列設定獨立下載密碼

在系列管理頁最上方「『系列名稱』專屬下載密碼」：

| 按鈕 | 作用 |
| --- | --- |
| 設定下載密碼／修改下載密碼 | 自己輸入兩次（6～64 字元）。修改後**舊密碼與已發出的下載授權立即失效** |
| 重新產生密碼 | 由伺服器產生 12 碼隨機密碼（例：`k7mp-x9qa-3hcd`），**只顯示這一次**，請立即複製並用 Messenger 提供給粉絲；舊密碼立即失效 |
| 停用密碼 | 粉絲暫時不能下載這個系列；已驗證的粉絲也立即不能再下載。其他系列不受影響 |
| 重新啟用密碼 | 恢復同一組密碼 |
| 立即撤銷 | 清除密碼並讓所有授權失效（例如密碼外流）。之後要設定新密碼才能再下載 |

狀態列顯示「未設定／已設定・啟用中／已設定・已停用」、第幾版、何時由哪位管理員更新。**後臺不會顯示密碼明文**（資料庫只存 bcrypt 雜湊，任何人都無法查看）；忘記時直接設定或重新產生新密碼即可。

規則（由後端強制，不是只把按鈕藏起來）：
- 粉絲下載某個系列時，只驗證**該系列**的密碼；其他系列或原本收藏館的密碼一律無效。
- 通過 A 系列密碼，不能下載 B 系列（後端發出的授權只限該系列）。
- ZIP 下載同樣只會包含該系列的作品。
- 一次要下載多個系列時，每個系列都要分別輸入自己的密碼。
- 系列「已下架」、「關閉下載」或「密碼停用／撤銷」時，後端立即拒絕，即使粉絲手上有 15 分鐘內的授權也一樣。
- 同一來源 15 分鐘內輸錯 5 次會暫停（所有系列與原本收藏館合併計算，換系列也無法繞過）。
- 網站「網站設定 → 開放粉絲下載」是全站總開關：關閉時所有系列與原本收藏館都暫停下載。

## 五、刪除系列

系列管理頁最下方「刪除『系列名稱』…」：

1. 選擇作品的處理方式：
   - **把作品移到其他系列**：移過去的作品先設為草稿；編號重複時自動接在目標系列最大編號後面。
   - **連同作品與照片一起永久刪除**（無法復原）。
2. 輸入完整的系列名稱確認（資料庫端會再檢查一次）。
3. 系列的專屬密碼一併刪除；管理紀錄保留。

只想暫時不讓粉絲看到，請用「已下架」，不要刪除。

## 六、管理紀錄

「管理紀錄」頁列出兩位管理員新增／修改／刪除系列與作品，以及設定、重新產生、停用、啟用、撤銷下載密碼的時間、操作者與修改的欄位。
紀錄**不包含密碼內容**，任何人（包含管理員）都不能修改或刪除紀錄。

## 七、粉絲前臺使用流程

1. 開網站首頁 →「**KUMA STUDIO 原創系列**」看到所有公開的系列（封面、名稱、介紹、作品數、標語、查看系列）。
2. 點系列 → 系列頁只顯示這個系列的作品。可以：
   - 瀏覽全部作品、♡ 收藏
   - 查看身份證（系列有啟用時）：系列名稱、編號、稱號、作品照片、介紹、宣言、KUMA STUDIO
   - 製作專屬大頭貼：作品有多款大頭貼時先選款式（大頭貼 1、大頭貼 2…）；選這個系列的預設宣言或自己輸入，調整大小、顏色、位置，即時預覽，可「恢復原始圖片」；切換 Facebook／Instagram／LINE
   - 收藏卡（系列有啟用時）：看大圖、改成自己的宣言、下載單張、勾選多張或整套 ZIP
3. 按下載 → 輸入「**這個系列**」的下載密碼（透過 Facebook Messenger 向粉專索取）→ 下載。15 分鐘內同一個系列不用再輸入。
4. 換到另一個系列下載時，會要求輸入那個系列的密碼。

網站支援手機、平板與電腦；粉絲不需要註冊帳號。

- [ ] 系列管理中心 → 新增系列（先是草稿）
- [ ] 系列設定：介紹、標語、預設宣言、身份證標題、宣言名稱、收藏卡主題
- [ ] 上傳系列封面（與主視覺，選用）

- [ ] 「預覽粉絲頁面（含草稿）」確認畫面
- [ ] 設定或重新產生**這個系列**的下載密碼
- [ ] 公開作品 → 系列狀態改成「公開」
- [ ] 用手機開首頁，實際用新密碼下載一次
- [ ] 透過 Messenger 把新系列的密碼提供給粉絲
