# KUMA STUDIO 多系列｜測試報告

測試日期：2026-11-02（開發環境）

## 測試環境

- 本機 PostgreSQL 16 套用**全部正式 migration**（含本次 `20261103000000_kuma_studio_collections.sql`），以 anon／authenticated／service_role 身分實際執行 RLS 與權限。
- 下載功能直接執行**正式的 Edge Function 程式**（`supabase/functions/download/handler.ts`）。
- 瀏覽器：Playwright Chromium，手機（iPhone 13 模擬 390px）與桌機（1366px）。
- Auth 與 Storage 為「Supabase 相容測試伺服器」模擬，**不是真正的 Supabase**，正式網址仍需依下方「尚未測試」實測。

## 測試資料

| 系列 | 作品 | 密碼 |
| --- | --- | --- |
| 熊兔生命共同體（既有系列） | 3 張程式產生的純色測試圖 | 測試密碼 A |
| 熊大寵妻系列（新增） | **RR 提供的 5 組照片**（劇情照＋配套大頭貼，共 10 個檔案 → 5 款作品）；稱號、介紹依 RR 提供的故事填寫 | 測試密碼 B（管理員 B 設定） |
| 熊大寵妻系列：額外大頭貼 | **RR 另外提供的 4 張大頭貼**（IMG_4841、4843、4844、4845）加為 No.001～004 的第 2 款；No.005 花園那組與先前檔案完全相同，不重複加入 | 同上 |
| 熊兔甜蜜日常（新增，管理員 B 建立） | 2 張純色測試圖 | 由「重新產生密碼」產生 |

所有密碼都是測試密碼，只存在測試資料庫；測試程式不含正式粉絲密碼。
