# 每月更新操作手冊

每月更新只需要在網站的管理後臺操作，**不需要修改程式碼、不需要重新部署**。兩位管理員都可以操作，步驟相同。

預估時間：10–15 分鐘（20 張照片）

---

## 1. 準備照片

- 格式：PNG、JPG 或 WebP（透明背景請用 PNG）
- 單張 20MB 以內；建議長邊 2000–3000px，可節省 Supabase 免費空間
- 檔名可先取好作品名稱，例如 `早安.png`（上傳時會自動帶入為作品名稱，開頭的數字與底線會被去掉）

## 2. 登入

開啟 `https://<你的帳號>.github.io/<儲存庫名稱>/#/admin`，用自己的 email 與密碼登入。

## 3. （選擇）清除上個月的「本月作品」

**作品管理 → ② 發布 → 清除所有「本月作品」標記**
上個月的作品仍會留在「全部作品」，只是不再出現在首頁「本月大頭貼」區。

## 4. 上傳本月新照片

1. **① 上傳本月新照片** → 選擇「預設分類」（之後可逐張修改）
2. 保持勾選「標記為本月作品」
3. 點檔案選擇區，一次選取多張照片
4. 每張顯示「✓ 完成」即上傳成功。新照片是 **草稿**，粉絲還看不到

## 5. 填寫名稱、分類、排序

在下方清單（可切到「草稿」篩選）：
- **編輯**：作品名稱、分類、描述、標籤、作品日期
- **↑ ↓**：調整展示順序（越上面越前面）
- **點縮圖**：預覽在 Facebook／Instagram／LINE 的裁切效果
- 放錯照片：**替換** 或 **刪除**

## 6. 發布

1. 確認要發布的草稿已勾選（預設全選）
2. 保持勾選「同時把網站『最新更新日期』設為今天」
3. 按 **發布選取的草稿**

## 7. 確認前臺

點右上角 **查看網站 ↗**，重新整理，確認新作品出現在「本月大頭貼」與「全部作品」。

## 8. （選擇）更新公告與下載密碼

**網站設定**：
- 修改網站公告（例如「十二月聖誕限定上架囉！」）
- 若每月更換下載密碼：輸入新密碼兩次 → **更換下載密碼**，再到 Facebook 粉專公告新密碼。
  舊密碼與粉絲手上尚未用完的下載授權會立即失效。

---

## 常用設定說明

| 設定 | 位置 | 效果 |
| --- | --- | --- |
| 取消公開 | 作品管理 → 取消公開 | 作品從前臺消失，也無法下載 |
| 停止下載 | 作品管理 → 停止下載 | 作品仍可瀏覽與預覽，但不能下載 |
| 本月作品是否公開 | 網站設定 | 關閉時，標記為本月的作品對粉絲隱藏（適合預先上傳、指定日期再公開） |
| 開放粉絲下載 | 網站設定 | 全站暫停下載，仍可瀏覽 |

## 注意事項

- 刪除作品會同時刪除原圖與預覽圖，無法復原。請自行保留原始照片備份（Supabase 免費方案沒有自動備份）。
- Supabase 免費 Storage 為 1GB。後臺每張作品都顯示檔案大小，可留意總用量（Supabase Dashboard → Storage 也可查看）。
