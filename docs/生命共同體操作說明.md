# KUMA 熊兔生命共同體｜ONE HEART, ONE LIFE 操作說明

「熊兔生命共同體限定收藏館」是原本收藏館裡一個**獨立的主題系列**：資料表、後臺頁面、下載範圍都和原本的作品分開，互不影響；下載密碼、兩位管理員帳號、Facebook／Instagram／LINE 大頭貼編輯器則沿用原本的。

- 粉絲入口：首頁的「熊兔生命共同體限定收藏館」卡片，或直接開 `網站網址/#/life`
- 單款作品頁：`網站網址/#/life/1`（No.001）～ `#/life/10`
- 管理後臺：`網站網址/#/admin` → 上方「生命共同體」

## 一、新增的功能

| 功能 | 說明 |
| --- | --- |
| 十款獨立作品 | 每款一筆資料：自己的原始照片、編號（No.001）、專屬稱號、作品名稱、主題概念、生命共同體介紹、專屬愛心宣言、保護區域、排序、公開／下架、開放下載 |
| 待上傳狀態 | 還沒上傳照片的作品顯示「待上傳」，粉絲看不到，也不能被設為公開（資料庫層級限制）。不會放入任何虛構或 AI 生成的照片 |
| 系列首頁 | 主視覺（No.001 照片）、KUMA 熊兔生命共同體、ONE HEART, ONE LIFE、主題句、系列說明；「查看身份證」「製作宣言大頭貼」「收藏卡」三個入口；十款作品卡片（照片、No.、稱號、作品名稱、查看身份證／製作大頭貼／收藏卡）；♡ 我的收藏 |
| 熊兔生命共同體身份證 | 每款一張：作品照片、生命共同體編號、專屬稱號、作品名稱、生命共同體介紹、專屬愛心宣言；可切換上一款／下一款 |
| 生命共同體宣言製作器 | 沿用原本的大頭貼編輯器：預設帶入該款宣言；可點選 10 句系列預設宣言、自由輸入（繁中＋Emoji）、修改或刪除、調整大小／顏色／位置、即時預覽、「恢復預設」與「恢復原始圖片（移除文字）」 |
| 保護區域 | 每款標出「臉與耳朵」「胸口（愛心）」；粉絲的文字**自動避開**這些區域（拖到臉上也會停在最近的空位），三個平台的裁切**不會切掉**這些區域（放大或拖曳到會切掉時自動停住） |
| 三個平台各自裁切 | Facebook（圓形）、Instagram（圓形，多留邊）、LINE（方形）各有自己的預設構圖與裁切，可分別調整；編輯器下方同時顯示三個平台的小預覽 |
| 大頭貼下載 | 通過下載密碼後，以**原始照片**重新合成正方形 PNG：Facebook／LINE 至少 1080px（依原圖裁切像素，最多 2048px）、Instagram 1080 × 1080；檔名如 `KUMA_FB_生命共同體_No.003_星空守護體.png` |
| 收藏卡 | 每款一張 1200 × 1800 高畫質 JPG：照片為主視覺、No. 編號、專屬稱號、作品名稱、介紹、宣言、KUMA STUDIO 與 ONE HEART, ONE LIFE；所有文字都在照片下方，不遮住熊兔。可選「官方宣言」或「我的宣言版本」 |
| 收藏卡下載 | 單張下載、勾選多張打包 ZIP、一次下載完整十張 ZIP；全部需要下載密碼 |
| 我的收藏 | 粉絲按 ♡ 收藏喜歡的編號，只存在自己的瀏覽器（不需要帳號、不上傳） |

### 儲存方式（避免重複）

- 每款只存**一張原圖**（私有 `originals` bucket，路徑 `life/<作品 id>/…`，位元組與上傳檔案完全相同）＋**一張公開預覽圖**（`previews` bucket，最長邊 1200px，供網頁顯示）。
- 公開預覽圖只用於網頁顯示；所有下載（大頭貼、收藏卡）都以私有原圖製作，不會用預覽圖取代原圖。
- 收藏卡與粉絲大頭貼在下載當下於瀏覽器合成，不另外存檔（因此沒有 `collection_card_url` 欄位，也不佔 Storage 空間）。
- 替換照片時，新檔上傳成功、資料更新後才刪除舊檔。

## 二、粉絲操作流程

1. 進入首頁 →「熊兔生命共同體限定收藏館」。
2. 瀏覽十款作品，選一個喜歡的編號（可按 ♡ 收藏）。
3. 「查看身份證」看稱號、介紹與宣言；或直接「製作大頭貼」。
4. 在編輯器選一句預設宣言或輸入自己的文字，調整大小、顏色、位置（文字不會遮住臉、耳朵與愛心）。
5. 上方切換 Facebook／Instagram／LINE，分別調整裁切。
6. 按「下載我的專屬大頭貼」→ 輸入 Facebook Messenger 私訊取得的下載密碼 → 下載。
7. 收藏卡：作品頁「查看與下載收藏卡」可下載單張（可改成自己的宣言）；系列首頁下方可勾選多張或一次下載十張 ZIP。

驗證成功後 15 分鐘內再下載不需重新輸入密碼。

## 三、管理員操作

### 第一次：上傳十張照片

1. 登入後臺 →「生命共同體」。清單裡已經有 No.001～No.010 十款（稱號、主題概念、宣言已依需求填好，狀態為「待上傳」）。
2. 在「上傳照片（可一次選多張）」一次選取十張照片。
   - 檔名有編號（`No.003.jpg`、`003_星空.jpg`、`生命共同體003.png`）會對應到該編號。
   - 其他檔名（例如手機的 `IMG_4755.jpeg`～`IMG_4764.jpeg`）依檔名順序填入 No.001、No.002…。
   - 上傳前清單會顯示每個檔案對應哪一款，可以用下拉選單修改。
3. 按「開始上傳」。每張照片各自建立／更新為一款獨立作品（草稿）。
4. 逐款按「預覽收藏卡」、點縮圖預覽大頭貼，確認沒問題。
5. 按「公開所有已上傳的草稿」（或逐款按「公開」）。

> 也可以對單一款按「上傳照片」／「替換照片」。

### 修改內容

- **編輯資料**：作品編號、排序、專屬稱號、作品名稱、主題概念、生命共同體介紹、專屬愛心宣言、是否開放下載。
- **系列設定**：系列名稱、英文名稱、主題句、系列說明、粉絲可選的預設宣言（一行一句）、系列排序、系列是否公開（關閉時首頁入口與整個收藏館都會隱藏）。
- **保護區域**：用滑桿把框框對準「臉與兩邊耳朵」「胸口愛心」。十款都已依原始照片預先量好；若替換成構圖不同的照片，請重新調整。
- **↑ ↓**：調整排序。**下架**：粉絲立刻看不到。**刪除**：資料與照片一起刪除（無法復原）。
- **預覽粉絲頁面（含草稿）**：開 `#/life?preview=1`，草稿也會顯示並標示「草稿」，不提供下載。
- **粉絲實際看到的頁面**：開 `#/life`，只顯示已公開的作品。

### 之後新增 No.011、No.012…

1. 「上傳照片」選新照片 → 自動對應到「新增作品」No.011（或按「＋ 新增一款」先建立空白作品，再上傳照片）。
2. 「編輯資料」填稱號、名稱、介紹、宣言 →「保護區域」對準臉、耳朵與胸口 → 「公開」。

不需要修改程式或重新部署。
